# Genie 2 (Google DeepMind, Dec 2024)

**Links**: https://deepmind.google/blog/genie-2-a-large-scale-foundation-world-model/

Predecessor to Genie 3 (see [genie.md](genie.md) for 3's details) — this note
is the delta/history, kept separate since it's the direct predecessor Joe
asked to compare against.

## What it added over Genie 1
Genie 1 only generated 2D worlds (trained on ~30,000 hrs of 2D platformer-
style footage). Genie 2 is the jump to **general 3D worlds** from a single
prompt image (generated by Imagen 3 from a text description, or a real photo)
— first/third-person avatars, complex characters, physics (water, smoke,
gravity, lighting, reflections), object affordances (bursting balloons,
opening doors), and even basic NPC modeling.

## Architecture
Explicitly disclosed (unlike Genie 3): an **autoregressive latent diffusion
model**. Frames pass through an autoencoder, latents feed a large causally-
masked transformer dynamics model (LLM-style causal mask), sampled
autoregressively frame-by-frame with classifier-free guidance for action
controllability.

## Key limitation vs. Genie 3
"Long horizon memory" in Genie 2 = consistent world for **up to a minute**,
with most demo examples only 10-20 seconds. Genie 3 explicitly improved this
plus added real-time speed — Genie 2's blog post admits the flashy demo clips
were from an **undistilled base model** (slow, not real-time); a distilled
real-time version existed but with reduced quality, and DeepMind didn't
publish numbers for that gap. This "demo quality vs. real-time quality"
tradeoff is the main thing Genie 3 fixed (shipped as real-time-by-default at
24fps/720p) along with promptable world events (new in 3).

## SIMA integration precedent (worth noting for our agent-integration doc)
Same pattern DeepMind repeated in Genie 3: generate a world from an image
prompt, then let the **SIMA** agent act in it via keyboard/mouse while Genie
2 renders consequences, with instructions like "open the blue door" / "go
behind the house". This is the earliest concrete evidence of the
agent-drives-world-model loop in integration-ideas.md #1/#2 — Genie 2, not 3,
is where DeepMind first demonstrated it publicly.

## Access
Never released publicly beyond the blog demos — no API, no weights, more
closed than even Genie 3's gated Project Genie. Purely a literature reference.
